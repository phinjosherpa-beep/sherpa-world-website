SHERPA WORLD — SINGLE-PAGE WEBSITE

This version combines the original Home, About, Explore, Get the App, Contact, Privacy and Terms pages into one index.html with in-page navigation.

Files:
- index.html: all website page content in one HTML file
- assets/styles.css: shared design stylesheet
- assets/site.js: mobile navigation and footer year script
- assets/images/: website photographs and logo

To preview: open index.html in a web browser.
To publish on GitHub Pages: upload the contents of this folder to the root of the repository (keep the assets folder beside index.html).

The Google Play badge remains marked as coming soon until an official listing URL is supplied. Review the draft Privacy and Terms sections before publication.
